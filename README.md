# VOLTIX — PJ4 Product Launch Website

A responsive two-page product launch concept built from the supplied `sic_mobile_spec_PJ1.xlsx` workbook.

## Pages
- `index.html` — promotional homepage with campaign story, feature highlights and product spotlight.
- `product.html` — product detail page with listed price/rating, complete specification table, feature explanations and FAQs.

## Supporting files
- `styles.css` — responsive visual system and CSS-only phone artwork (no external product image dependencies).
- `script.js` — mobile navigation and demo add-to-bag interaction.
- `products.json` — normalized export of all 413 workbook product rows for future catalog/filter extensions.

## Run locally
Keep all files in the same folder, then open `index.html` in a modern browser. No build step or package installation is required. Google Fonts load online; fallback fonts are defined.

## Featured product and source notes
The featured product is **Voltix Hyper67 5G (256 GB)**, the first record in the workbook:
- Listed rating: 4.9
- Listed price: $1,000 (currency code is not specified in the workbook)
- Camera field: 200
- Display: HD+ AMOLED, 6.7 inches
- Battery: 4,700 mAh
- Storage: 256 GB
- RAM: 4 GB
- Weight: 190 g
- Processor: Dimensity 9000 Processor

The website identifies VOLTIX as a fictional concept brand for this assignment. It does not use third-party logos or claim endorsement by a real brand. No unsupported features (such as refresh rate, charging speed, water resistance, review count or battery endurance) are invented. The rating is labelled as a workbook-listed rating, not as verified customer-review evidence.

The add-to-bag button is a demonstration interaction only. There is no checkout, inventory, payment processing or backend.
